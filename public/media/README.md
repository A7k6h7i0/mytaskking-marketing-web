# Media placeholders

Drop product screenshots and short silent clips here in Phase 2.

Suggested folders:

- `android/` — chat, calls, dashboard, check-in, telecaller, KYC, Sales Head
- `windows/` — sidebar, Work Activity, Sales Head nav
- `clips/` — 8–15s muted loops for proof strip

Keep filenames lowercase with hyphens, e.g. `android-dashboard.png`.
