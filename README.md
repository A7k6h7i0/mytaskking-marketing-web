# MyTaskKing Marketing Website

Marketing site for **MyTaskKing** — enterprise company workspace (chat, calls, tasks, telecaller CRM, attendance, org onboarding).

## Phase 1 (current)

- Brand foundation (teal/ink, Syne + Manrope)
- Home: hero, problem/solution, Android vs Windows, roles, media slots, CTA
- Features hub with 7 journey sections and screenshot/video placeholders

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command       | Description        |
| ------------- | ------------------ |
| `npm run dev` | Local development  |
| `npm run build` | Production build |
| `npm run start` | Serve production |
